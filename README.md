# African Ruby Community — Workshops

Hands-on sessions run by the [African Ruby Community](https://rubycommunity.africa).
Each workshop lives in its own folder with lessons, challenges, and supporting materials.

## Workshops

| # | Workshop | Description |
|---|----------|-------------|
| 01 | [Intro to Ruby](01-intro-to-ruby/) | Variables, strings, arrays, loops, methods |
| 02 | [Intro to Git & GitHub](02-intro-to-git-github/) | Version control, commits, branches, pull requests |

## Structure

Each workshop folder follows the same layout:

```
NN-workshop-name/
├── lessons/       # Short lessons with runnable examples
├── challenges/    # Starter files with TODOs
├── docs/          # Handout, common mistakes, cheat sheet
├── notes/         # Slide content, references, session plan, quiz
├── demo/          # Live demo repo and script (where applicable)
└── README.md      # Workshop overview and setup instructions
```

## Contributing

To add a new workshop, create a `NN-workshop-name/` folder following the structure above,
and add a row to the table in this file.

Open an [issue](../../issues/new/choose) to report a mistake or suggest an improvement.
Pull requests that fix typos or add clearer explanations are welcome.
