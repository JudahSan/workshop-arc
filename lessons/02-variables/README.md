# Lesson 2: Variables

**Goal:** store a value with a name, then use it.

A **variable** is a labelled box. We put `"Faith"` in a box called `name`.
In Ruby you do not declare it first. You just make it.

```ruby
name = "Faith"
age = 20
puts name
puts age + 1
```

Output:

```
Faith
21
```

## Remember

- `puts` prints to the screen.
- Ruby is **case sensitive**: `name` and `Name` are different things.
- A variable name must start with a lowercase letter.

## Try it

- Change `age` to your own age. What does `age + 1` print?
- What happens if you write `puts nmae` (a typo)? Read the error message.
