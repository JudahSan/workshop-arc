# Lesson 1: Get set and say hello

**Goal:** run one line of Ruby on your own computer (or in a Codespace).

## Setup

Pick one way to run Ruby (details in the [main README](../../README.md#getting-started)):

- **GitHub Codespaces**: nothing to install.
- **Local install**: check with `ruby -v`.
- **No laptop?** Pair up with a neighbour, or follow the printed [handout](../../docs/handout.md).

## Your first line

```ruby
puts "Hello, KCC!"
```

`puts` prints text to the screen.

```bash
ruby lessons/01-hello/hello.rb
```

You should see:

```
Hello, KCC!
```

Any Ruby file is run the same way: `ruby filename.rb`.
