# Lessons

Work through these in order. Each folder has a short `README.md` and a runnable `.rb` file.

| # | Lesson | You will learn | Run it |
|---|--------|----------------|--------|
| 0 | [A program you can already read](00-readable-ruby/) | Ruby reads like English | `ruby lessons/00-readable-ruby/readable.rb` |
| 1 | [Hello, Ruby](01-hello/) | `puts`, running a file | `ruby lessons/01-hello/hello.rb` |
| 2 | [Variables](02-variables/) | Labelled boxes for values | `ruby lessons/02-variables/variables.rb` |
| 3 | [Strings](03-strings/) | Text, `#{ }`, `upcase` | `ruby lessons/03-strings/strings.rb` |
| 4 | [Arrays](04-arrays/) | Lists, counting from 0, `<<`, `p` | `ruby lessons/04-arrays/arrays.rb` |
| 5 | [Loops](05-loops/) | `each do \|item\| ... end` | `ruby lessons/05-loops/loops.rb` |
| 6 | [Methods](06-methods/) | `def`, reusing code | `ruby lessons/06-methods/methods.rb` |

Then try the [challenges](../challenges/).

**Tip:** type the code yourself instead of copy-pasting. You will make typos,
and reading the error messages is part of learning.
