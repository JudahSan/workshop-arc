# Lesson 0: A program you can already read

**Goal:** see that Ruby reads almost like English, before you learn a single rule.

Open [`readable.rb`](readable.rb) and read it out loud:

> If the day is Saturday or Sunday, say it's the weekend, else say back to class.

You have not learned Ruby yet, and you can still tell what it does. That is the point.

## Run it

```bash
ruby lessons/00-readable-ruby/readable.rb
```

## Think about it

1. What will it print?
2. Change `day` to `"Monday"`. What happens now?
3. What makes code easy to read?
