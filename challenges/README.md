# Challenges

Two challenges, one for each level. Pairs are welcome.

| Level | File | Task |
|-------|------|------|
| Easy | [`easy_greet_names.rb`](easy_greet_names.rb) | Print a greeting for each name in a list |
| Stretch | [`stretch_describe_day.rb`](stretch_describe_day.rb) | Print `weekend` or `weekday` for a day |

## How to work on them

1. Open the file and read the comments at the top.
2. Replace the `# TODO` with your own code.
3. Run the file to see your output:
   ```bash
   ruby challenges/easy_greet_names.rb
   ```
4. Run the tests to check your answer:
   ```bash
   rake test
   ```
   (No `rake`? Use `ruby test/challenges_test.rb`.)

Tests fail until you finish the methods. That is normal. A red test is just a
hint about what to fix.

## Stuck?

- Re-read the matching lesson.
- Check [common mistakes](../docs/common-mistakes.md).
- Try again before you peek at the [`solutions/`](../solutions/) folder.
- Ask a question: open an issue on GitHub, or ask your instructor.

If you are short on time, do the easy one and finish the stretch at home.
