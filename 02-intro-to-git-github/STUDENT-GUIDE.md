# GitHub for Students

GitHub is useful beyond storing code: you can collaborate on projects, show your work in a portfolio, and learn tools used by professional developers. A GitHub account is free; student benefits are an optional extra that you apply for after creating your account.

## Create your GitHub account

1. Go to [github.com/signup](https://github.com/signup) and create a personal account with an email address you can access.
2. Choose a professional username you are comfortable sharing on your portfolio and with employers.
3. Verify your email address and enable two-factor authentication to help protect your account.
4. Add a profile photo or short bio if you want, and create a repository for a project you would like to share.

## Apply for GitHub Education

Eligible students can apply for GitHub Education and the [Student Developer Pack](https://education.github.com/pack), which offers access to GitHub education resources and free or discounted tools from partner companies. The specific offers can change, so check the Pack for current details.

1. Make sure you have a GitHub account and are enrolled in a degree- or diploma-granting program. Applicants must be at least 13.
2. Gather proof of current student status, such as a student ID showing current enrollment, class schedule, transcript, or enrollment verification letter.
3. Go to [GitHub Education benefits](https://github.com/settings/education/benefits), select **Start an application**, complete the form, and submit it.
4. If asked, add and verify your school email address first. If you do not have one, follow GitHub's instructions for providing official documentation.
5. After approval, visit the [GitHub Education portal](https://github.com/education) to see and claim available benefits.

## Activate GitHub Copilot Student

Verified students can get free access to GitHub Copilot's student plan and premium features. Verification and Copilot activation are separate steps:

1. Complete GitHub Education verification as described above.
2. Open [Education benefits](https://github.com/settings/education/benefits).
3. Under **Free GitHub developer resources for students and teachers**, select **Learn more**, then follow the prompts to activate Copilot Student and choose your usage policies.
4. Use Copilot as a learning aid: review and test its suggestions, and make sure you understand code before using it.

If Copilot still shows a free plan or a paid checkout after student approval, activation may take several days. Do not purchase a plan just to activate the student benefit; wait and retry, then contact GitHub Support if needed.

## Other student benefits

- **Student Developer Pack:** Explore the current partner offers and claim the ones that are useful to your learning or projects.
- **GitHub Codespaces:** Verified students receive a monthly Codespaces allowance for personal accounts. Check GitHub's [Codespaces billing details](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces) for current limits.
- **Portfolio and collaboration:** Use repositories, issues, and pull requests to demonstrate your work and collaborate on projects. You can also publish a static site using [GitHub Pages](https://pages.github.com/).

Benefits, eligibility checks, and usage limits can change. Refer to GitHub's official [student application guide](https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student) for the latest requirements.
