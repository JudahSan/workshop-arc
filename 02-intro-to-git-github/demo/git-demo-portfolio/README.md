# git-demo-portfolio

A tiny personal portfolio site used in the "Intro to Git and GitHub" workshop.
Everything here is small on purpose — you can read all of it in two minutes.

## About me (edit this!)

## What's inside

| File | Purpose |
|------|---------|
| `index.html` | The portfolio page (works with GitHub Pages) |
| `style.css` | Colours and layout |
| `notes.txt` | A tiny file used to practise merge conflicts |
| `.gitignore` | Tells Git which files to never track (like `.env`) |
| `.env.example` | Shows what a secrets file looks like — fake values only |
| `CONTRIBUTORS.md` | Add your name here for the student challenge |

## Run it locally

Open `index.html` in your browser. No installs needed.

## Publish it with GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set source to **main branch / root**.
4. Your site will be live at `https://your-username.github.io/git-demo-portfolio`.
