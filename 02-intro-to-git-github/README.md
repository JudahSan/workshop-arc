# Workshop 02: Intro to Git & GitHub

Git tracks changes to your work. GitHub hosts Git repositories and helps people collaborate.

## What you'll learn

- The difference between Git and GitHub
- How to create commits and review changes
- How to use branches and resolve merge conflicts
- How to push a project to GitHub and open a pull request
- How students can apply for GitHub Education and activate Copilot Student

## Get started

Install Git from [git-scm.com](https://git-scm.com), then check that it works:

```bash
git --version
```

Set the name and email that will appear on your commits:

```bash
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
```

Use the [Git cheat sheet](CHEATSHEET.md) for common commands.

New to GitHub or applying for student benefits? Read the [GitHub student guide](STUDENT-GUIDE.md).

For more reading on version control, Git, and GitHub, see the [references](REFERENCES.md).
